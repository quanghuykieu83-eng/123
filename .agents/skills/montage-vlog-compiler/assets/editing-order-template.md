## 连续性检查

- [ ] 没有黑帧、空档或异常重叠。
- [ ] 关键语义有可见的画面落点。
- [ ] 同源素材没有连续或高频重复。
- [ ] 远景、中景、近景、人物、环境和细节有变化。
- [ ] 转场两侧有真实可用余量。
- [ ] 口播完整，音乐和环境声不遮挡人声。
- [ ] 字幕与真实口播同步。
- [ ] 时间线保持可编辑，旧版本未覆盖。
