# CHANGELOG

## v0.4 — 2026-08-28

### 修正
- README 曾把「参考片学习」标为未实测。这是错的：逐条分析参考片、提炼风格档案，正是本方法的来源，不是未验证的分支。原表述混淆了「这件事没做过」与「打包后未用本说明书原样重跑一次」，后者属内部记录，不应出现在公开文档。

### 新增
- `examples/worked-example.md`：从文案到执行单的完整填写样例，逐栏说明粒度，并演示缺口如何如实记录。此前六个模板全是空表格，新用户无从判断该写多细。
- README 新增「它不会给你什么」「你还需要一个执行器」「大概要多久」三节。产出的是可编辑初剪的指令，不是成片；没有能读指令的执行器就只有文档，这一点此前没有写明。
- README 补 ffmpeg 安装命令，并写明 `media_inventory.py` 只能扫描单个目录及其绕行办法。

### 方法
- 新增「相邻镜头的方向连续性」：切点方向匹配的判定与处理顺序，含「素材不合适时不强用」的边界与两类反例。
- 新增「技巧性转场」：只用在方向已匹配的切点上强化连续性，不用于遮盖对撞；类型服从情绪；证据短切段不用。

### 重构
- 执行器层去掉具体产品命名，执行提示词模板统一为 `assets/executor-prompt-template.md`，面向任意剪辑工具或 Agent。

## v0.3.1 — 2026-08-28

### 修正
- 适用范围原写作「不适用于母婴以外的题材」，是把**未验证**当成了**不适用**。方法本身面向情绪混剪，不限定题材；只有验证范围限于母婴。已改为分开陈述，并在 SKILL.md 里写明两者不得混写。
- `description` 同步放宽到情绪混剪，保留真正不适用的类型。

## v0.3 — 2026-08-28

范围收窄、首轮真实实测、准备公开。

### 新增
- README.md：适用范围、**如实的验证状态表**、推荐操作顺序、持续更新原则。
  「推荐操作顺序」只写操作这个 skill 的步骤与乱序代价，不含设备环境或个人偏好类建议。
- LICENSE（MIT，署名待发布者填写）。
- 「相邻镜头方向连续性」：切点方向匹配的判定与处理顺序，含「素材不合适时不强用」的边界与两类反例。
- 「技巧性转场」：只用在方向已匹配的切点上强化连续性，不用于遮盖对撞；类型服从情绪；证据短切段不用。

### 范围
- 适用范围限定为**母婴情绪混剪**。不再声称跨题材通用性。
- `description` 改为纯触发条件，不再摘要工作流。
- 说明纯音乐卡点为何不适用：缺口播即缺时间主轴。

### 证据机制
- 素材证据按读取方式拆为 `verified_meta` / `verified_still` / `verified_motion` / `verified_audio`，并给出各级的能力边界表。
  起因：实测中只看过静帧就写出了动作起落、转场余量与声音听感的结论。
- 素材卡与其置信度分值明确定性为未验证的第三方描述，只可召回、不可排序。
- 新增时间状态 `text_only`（只有文案、无任何音频）。

### 停止条件
- 「停止条件」改为「分级停止」：按缺失输入列出仍可执行与禁止执行的部分。
  起因：原条件宽到任何第一轮都会触发，结果被整体无视。

### 安全
- 定义「高风险素材」为可观察内容，并解除与「原始素材只读」的矛盾：优先收紧入出点，副本写到独立目录。
- 素材库在可卸载卷或网络卷上时，记录挂载点并在使用前确认。

### 模板
- 语义锚点表的「SRT 时间」列改为「时间」，并说明各时间状态下的来源。无音频时不得填 SRT 时间码。
