# 参考 Vlog 风格学习

## 分析顺序

1. 登记全部参考片、来源和可分析范围。
2. 读取媒体信息、实际显示方向、音轨和总时长。
3. 若参考片是平台录屏，只分析真实成片区域，排除界面、手机框和操作浮层。
4. 为每条参考片生成转写、场景切点、代表帧和可定位的观察记录。
5. 逐条分析后再做跨样本归纳，不用少量抽样代替用户指定的完整参考集。

## 分析维度

- 文案结构、开头、转折、核心句和结尾。
- 情绪起点、推进、变化和余韵。
- 文案与画面的字面、情绪、因果或反差关系。
- 环境、人物、动作、细节以及远中近景分布。
- 镜长档位、快慢变化、动作切点和转场语言。
- 旁白、音乐、动作声、环境声、留白和字幕包装。
- 自然叙事段、产品说明段或其他功能段的差异。

## 归纳规则

把观察分别放入：

- `stable_pattern`：多个样本重复出现且能定位证据。
- `single_video_trait`：只出现在个别样本。
- `user_preference`：用户主动选择或否定。
- `hypothesis`：当前看似合理但尚未跨样本或实测验证。

不要从参考片复制原句、作者名称、独特品牌元素或专属数值进入公开风格档案。提炼关系和方法，不仿冒创作者身份。

## 风格档案要求

使用 `assets/style-profile-template.md`，并为每条规则填写来源、状态、适用范围和反例。镜长、BPM、音量和转场时长只能作为带证据的范围或测试起点，不能写成永久公式。
