# 偏好学习状态机

## 原则

修改不自动等于长期审美。先保存证据和候选规则，再由用户确认归类。

```text
检测到修改
→ 保存修改前后与用户原话
→ 解释单片问题
→ 抽象候选规则
→ 写明适用范围与反例
→ 用户确认归类
```

## 五种归类

- `long_term_preference`：用户确认以后跨项目复用。
- `project_preference`：只用于当前题材、系列或项目。
- `single_edit`：只解决当前片的一个位置。
- `compliance_fix`：由隐私、授权、平台或安全引起，不计入审美。
- `rejected`：用户否定，不学习。

## 候选偏好最小证据

- 修改前与修改后；
- 对应文案、时间、镜头或声音位置；
- 用户原话和修改原因；
- 当前题材与情绪目标；
- 候选规则；
- 适用范围、反例和建议归类；
- 用户最终确认状态。

## 写入长期风格的条件

同时满足以下条件：

1. 修改前后证据可读回。
2. 用户明确表达“以后也这样”或同义意思。
3. 规则没有把单片素材、合规修正或执行器缺陷误当审美。
4. 适用范围与反例明确。

用户可以撤回或把长期偏好降级为项目偏好。保留变更记录，不静默覆盖旧规则。
