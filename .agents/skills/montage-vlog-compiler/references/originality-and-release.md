# 原创边界与发布记录

## 方法来源

本 Skill 的核心方法来自作者自己的真实 Vlog 剪辑过程、用户修改反馈和项目内验证记录。公开包重新组织为六阶段编译流程，并独立编写说明、模板和工具代码。适用范围限定为母婴情绪混剪，见 SKILL.md「适用范围」。

公开包不包含：

- 外部 Skill 或仓库的代码、测试、模板和大段文字。
- 外部创作者的姓名、原句、专属镜长、比例或风格参数。
- 私人素材、内部项目路径、客户文件和一次性案例信息。
- 未经验证却写成普遍规律的产品能力或审美公式。

行业通用概念，例如素材清单、哈希校验、SRT、时间码、逐镜执行单和连续试听，不归任何单一项目独有；使用时保持自己的结构、命名、实现和证据链。

## 维护来源记录

每次吸收新方法时记录：

1. 来源是作者实测、用户反馈、公开资料还是外部项目。
2. 实际吸收的是通用问题、接口事实还是具体表达。
3. 是否包含可受版权保护的文字、代码、模板或独特结构。
4. 如何独立重新设计，以及对应的测试证据。
5. 哪些内容因来源或授权不清而未采用。

如果参考外部项目，只记录“它帮助确认了什么通用问题”，不要复制或近似改写它的文字、代码、模板、测试和独特组织方式。

## 发布前检查

- [ ] 全包搜索私人路径、内部项目名、客户名和参考创作者名，结果为零。
      作者本人的公开署名不算泄漏；扫描要针对**完整路径**，不要用署名里的词做模糊匹配，否则会互相误报。
- [ ] 每个方法都能指向作者自己的实测或用户确认记录。
- [ ] 新增代码有独立功能测试，没有复制外部实现。
- [ ] 第三方依赖、素材和示例具有明确许可。
- [ ] README、许可证和作者署名由发布者最终确认。
- [ ] 用一条全新的母婴素材与文案做前向测试，确认没有偷带内部案例参数、路径或镜头。
- [ ] 未通过的真实产品能力仍标为待验证。
