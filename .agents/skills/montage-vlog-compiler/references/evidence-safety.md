# 证据、安全与授权契约

## 证据等级

| 状态 | 允许表达 | 不允许表达 |
|---|---|---|
| `verified_source` | 文本输入已直接读取 | 根据文件名或计划猜测 |
| `verified_meta` | 工具读出的媒体属性 | 把「有音轨」说成「听过」 |
| `verified_still` | 静帧里看得见的东西 | 从静帧推断动作、抖动或焦点 |
| `verified_motion` | 连续播放看到的画面 | 顺带把声音也说成已验证 |
| `verified_audio` | 实际试听到的声音 | 把设计意图写成听感结论 |
| `verified_executor` | 已从实际时间线或产物读回 | 根据执行器自报推断画面和听感 |
| `user_feedback` | 用户明确说喜欢、不喜欢或修改原因 | 把用户沉默当作同意 |
| `confirmed_preference` | 用户明确要求以后复用 | 一次修改后自动长期学习 |
| `hypothesis` | 下一轮准备测试 | 写成稳定风格规则 |
| `pending_validation` | 明确缺少哪项检查 | 写成已完成、已锁定或已验收 |

## 读取方式的能力边界

素材证据按读取方式分级。每一级只能支撑它真正看得到的结论。

| 读取方式 | 能支撑 | 不能支撑 |
|---|---|---|
| 媒体属性（ffprobe 等） | 时长、编码、帧率、实际显示方向、音轨是否存在、哈希 | 画面内容、声音内容、可用性 |
| 静帧 | 场景、人物、景别、构图、是否有第三方或烧录图形 | 动作起点与落点、抖动、失焦漂移、变焦、剪辑余量 |
| 连续播放 | 动作起落、稳定性、可切位置、黑帧与误触 | 声音听感 |
| 试听 | 原声内容、噪声、人声清晰度、可用性 | 画面问题 |

结论写在哪一级，标签就只能标到哪一级。跨级书写必须改标 `pending_validation`。

素材卡、模型标签和它们自带的置信度分值都属于**未验证的第三方描述**，不属于任何一级。它们只能用于候选召回，不能用于排序，也不能替代真实画面检查。

## 输入边界

- 只读取用户指定路径，不扩大到整个照片库、磁盘或私人素材库。
- 素材库在可卸载卷或网络卷上时，记录挂载点，并在每次使用清单前确认卷已挂载。路径可能是软链接，清单里记的是解析后的真实路径。
- 不移动、改名、覆盖或删除原始视频。
- 为分析代理、安全片段和执行器素材包使用独立目录。
- 对未成年人、私人屏幕、住址、泳装、裸露、品牌和第三方人物执行额外人工复核。
- 素材卡或模型标签只用于候选召回，不能替代真实画面检查。

## 外部素材

仅在本地素材缺少关键语义锚点时补充外部素材，并保存：

- 原始页面与下载地址；
- 作者或上传者；
- 许可证及官方说明页；
- 下载日期；
- 当前用途和必要性；
- 是否可能暗示人物或品牌背书。

外部素材必须与原片的画质、光线、色调和生活感协调。来源或许可不清时不得使用。

## 输出边界

- 保持时间线和轨道可编辑。
- 未经明确授权，不导出、不发布、不上传、不发送给第三方。
- 工具自报、项目结构存在、完整播放、用户验收分别记录。
- 录屏缺头、缺尾或中间断档时只报告实际覆盖时长。
